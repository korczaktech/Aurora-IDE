# Front-End — Website

## Estrutura

- `HTML/`: páginas e marcação.
- `CSS/`: estilos e identidade visual.
- `JavaScript/`: interações da interface.
- `TypeScript/`: módulos tipados.
- `React/`: futura aplicação baseada em componentes.

## Estado atual

A primeira tela de demonstração está em `HTML/index.html`, com estilos em `CSS/style.css` e interações em `JavaScript/app.js`.

O frontend é independente do backend Rust. A comunicação com serviços será integrada depois da definição dos contratos de API.
