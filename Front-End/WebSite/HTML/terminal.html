Comandos locais

Enquanto o motor Rust não estiver conectado, somente comandos de interface são processados no navegador.

  • ajuda — lista os comandos locais.
  • limpar — limpa a saída visível.
  • echo texto — exibe texto informado.
  • versao — mostra a versão da interface.

Comandos de sistema, arquivos, processos e compilação não são executados nesta etapa.
