AURORA IDE · RECURSOS

Ferramentas para desenvolver.

A Aurora reúne uma interface de trabalho, serviços de conta e ferramentas de desenvolvimento. Esta página descreve o que está conectado atualmente e diferencia os componentes visuais dos serviços operacionais.

Conta e acesso

  • Cadastro e login: integração com a API da Aurora.
  • Sessão: consulta da conta autenticada e encerramento de sessão.
  • Permissões: identificação de contas administrativas e contas comuns.

Editor web

  • HTML, CSS e JavaScript: edição de arquivos no navegador.
  • Pré-visualização: execução da página de demonstração em um iframe.
  • Console: exibição de mensagens da pré-visualização.
  • Salvamento: armazenamento local no navegador, neste editor de demonstração.

O editor web não representa um workspace remoto e não compila linguagens nativas como Rust, C ou C++.

Terminal

  • Bash: sessões PTY executadas no servidor.
  • WebSocket: transporte de entrada, redimensionamento e saída da sessão.
  • Output: visualização da saída recebida do processo.
  • Controle de acesso: sessões associadas à conta e acesso restrito a administradores.

Importante: o terminal não é um sandbox. Ele executa comandos no ambiente do servidor e não deve ser usado por contas comuns ou para executar código não confiável.

Áreas ainda sem integração operacional

  • Debug Console: sem adaptador de depuração conectado.
  • Problems: sem analisador de código ou serviço de diagnóstico conectado.
  • Ports: sem serviço de encaminhamento de portas conectado.
  • O editor de demonstração não salva arquivos no sistema de arquivos remoto do servidor.

Infraestrutura

A interface web é servida como conteúdo estático. A API é desenvolvida em Rust e utiliza MongoDB para os dados de conta e sessão. A disponibilidade de recursos de backend depende da configuração e da saúde desses serviços.
