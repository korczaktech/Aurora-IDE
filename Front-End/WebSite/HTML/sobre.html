Sobre a Aurora IDE.

A Aurora IDE é um ambiente de desenvolvimento de software da Korczak Technologies. Sua arquitetura combina uma interface web com serviços de backend para autenticação e ferramentas de desenvolvimento.

O propósito

A Aurora busca reunir em um único ambiente a organização de projetos, a edição de código e ferramentas que apoiam o trabalho de desenvolvimento. A experiência é construída em torno de uma interface web e de serviços independentes.

Como é construída

A interface utiliza HTML, CSS e JavaScript. Os serviços de backend são desenvolvidos em Rust, com API HTTP e comunicação WebSocket para o terminal. O armazenamento de contas e sessões utiliza MongoDB, respeitando a estrutura compartilhada de contas da Korczak Technologies.

Estado dos recursos

O cadastro e o login são integrados à API. O editor web de demonstração trabalha com HTML, CSS e JavaScript, mantém os arquivos no armazenamento local do navegador e oferece pré-visualização no próprio navegador. O terminal remoto utiliza Bash no servidor e permanece restrito a administradores.

Nem todas as áreas visíveis da interface representam integrações concluídas. Recursos de depuração, análise de problemas e encaminhamento de portas ainda não possuem serviços funcionais conectados.

Segurança do terminal

O terminal executa Bash no ambiente do servidor e não é um sandbox. Por isso, seu uso é limitado a administradores confiáveis. Ele não deve ser disponibilizado a usuários comuns nem utilizado para executar código não confiável.

Desenvolvimento

A Aurora IDE é desenvolvida pela Korczak Technologies. Saiba mais no website institucional ou consulte o repositório do projeto.
